# 📱 Registration Form App

A simple Android application developed using Java and XML in Android Studio. The app provides a registration form where users can enter their personal information and view the submitted details in a pop-up dialog.

## ✨ Features
- Enter username and personal information
- Add email address and phone number
- Enter a password
- Select gender
- Accept terms and conditions
- Display registration details in a dialog
- Simple and user-friendly interface

## 🛠️ Technologies Used
- **Java** – Application logic
- **XML** – User interface design
- **Android Studio** – Development environment

## 🚀 Getting Started
1. Clone or download the repository.
2. Open the project in Android Studio.
3. Run the app on an Android emulator or a physical device.
